**Goal:** Constrain the semantic cache to strictly accept `RedactedPrompt`s to ensure raw secrets can never be hashed or matched in Redis.

**Architecture:** We will change `TieredSemanticCache` to accept `prompt: RedactedPrompt` in `.lookup` and `.store`, replacing `messages: list[dict[str, Any]]`. This isolates the cache key generation from raw messages. We will also add L2 semantic match logic if missing, or leave stubs for threshold validation. Finally, we will write integration tests proving a `str` fails type checking and that real cache hits happen.

**Tech Stack:** Python 3, pytest, redis (AsyncRedisLike mock for tests)

```python
...
    def _build_key(
        self,
        model: str,
        prompt: RedactedPrompt,
        params: dict[str, Any] | None,
    ) -> str:
        canonical = json.dumps(
            {"model": model, "prompt": prompt, "params": params or {}},
            sort_keys=True,
            separators=(",", ":"),
        )
        return hashlib.sha256(canonical.encode("utf-8")).hexdigest()
```
