# Mutation rows whose neutralised verdict cannot be established without some part of the
# environment, one per line:
#
#   Q-NN: requires=ENV_VAR  reason
#
# Read by `scripts/control-of-the-control.py`. The `requires=` clause is mandatory and is what keeps
# this file from becoming the trap it would otherwise be. A flat exemption list would make the check
# pass where the environment is missing and fail where it is present -- an assertion whose verdict
# depends on who runs it, which is precisely how a stale constant survived for months in this
# repository as an "environment note". Instead a row is skipped only where its named variable is
# ABSENT; wherever that variable is set the row is judged like any other and must flip to VACUOUS.
#
# THE FILE IS EMPTY, AND ALL THIRTY-ONE ROWS ARE JUDGED IN CI.
#
# Until this pass `control-of-the-control.py` ran in no workflow at all, so nothing anywhere checked
# whether the negative controls were still negative. Wiring it into `mutation-ci.yml` found four rows it
# could not attribute, and every one was the job's environment rather than the row:
#
#   Q-04, Q-16, Q-17  their properties skipped for want of `FORGEOPS_TEST_DATABASE_URL`, and a control
#                     that exercises nothing proves nothing. Fixed by exporting it.
#   Q-20              needs the real Cerbos sidecar, because it asks the sidecar rather than a Python
#                     reimplementation of it. Fixed by starting Cerbos in the job.
#   Q-19              builds the real application and enumerates `create_app().routes`, so it needs the
#                     model-tier settings that decide route composition. It does NOT need a reachable
#                     model server -- nothing in the property calls a model -- so the job sets
#                     `SELF_HOSTED_BASE_URL` to a port nothing listens on. That is deliberate: if a
#                     future change made the property depend on a live endpoint, it would fail here
#                     rather than silently start requiring one.
#
# Adding a line back is a decision that a negative control should exist and never be checked. That is
# almost never the right answer.
